- 2026-05-15: Phase 3 / Chunk 10 — switch resume PDFs to private Blob access (production fix). Prod was throwing `Vercel Blob: Cannot use public access on a private store` on every PDF import because the `resume-pdfs` store is intentionally private and `src/lib/resumes/create.ts` was passing `access: 'public'` to `put()`. Fix flips to `access: 'private'` and rewires `src/lib/ai/resume-importer/index.ts` to call `get(pdfUrl, { access: 'private' })` from the `@vercel/blob` SDK to stream bytes server-side, then sends them to Claude as a base64 document source (no URL leaks to Claude). Chose this over signed-URL approach because the SDK has no presigned-URL primitive for private blobs (`getDownloadUrl()` only appends `?download`) — option (a) is also cleaner to test (one SDK mock). Updated `resume-importer.test.ts` to mock `@vercel/blob` and assert the message content is `{ type: 'base64', media_type: 'application/pdf', data: <b64> }`; added a missing-blob test. `createResumeForUser.test.ts` now asserts `access: 'private'`. 1 new test, total 43 passing; typecheck, lint, build all green. Vercel deploy `3d875cc` green. ADR-013 (resume PDFs use private Blob access) added to bjc-portfolio.
